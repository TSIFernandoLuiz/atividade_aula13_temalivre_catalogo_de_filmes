O que é o CineGrid?

Um projeto acadêmico focado em exibir o verdadeiro poder e a flexibilidade do CSS Grid Layout na construção de interfaces web cinematográficas e modernas.

Missão

Proporcionar a melhor experiência de usuário no mapeamento e catalogação de obras cinematográficas, garantindo performance e responsividade irretocáveis em todos os dispositivos.

Visão

Tornar-se a referência em design de interfaces para plataformas de streaming na disciplina de Desenvolvimento de Sites, superando padrões convencionais.

Valores

Inovação, código limpo, estruturação semântica, acessibilidade e, acima de tudo, abandono de técnicas obsoletas de layout.

Stack Tecnológico

HTML5 Semântica
CSS3 Estilização Global
CSS Grid Motor de Layout
Mobile First Responsividade
